## Execution principles

- Customization must preserve menu feasibility, ingredient availability,
  equipment needs, service speed, ordering clarity, guest flow, and venue rules.
- Visual treatments must preserve contrast, legibility, working surfaces,
  equipment access, and safe guest access.
- Exact artwork formats, print specifications, quantities, and deadlines remain
  content dependencies until the selected branding surfaces are scoped.
- Rental styling cannot name unapproved styles, finishes, dimensions,
  quantities, or availability.

## Bloat-control decisions

- Seventeen topics reuse existing definitive answers and page sections.
- One direct rental-styling FAQ and one corresponding question-map record were
  added because no existing answer addressed both visual direction and
  operational layout.
- No customization route, resource article, duplicate branding module, or new
  schema type was created.
